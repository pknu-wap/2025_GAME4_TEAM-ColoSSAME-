작업을 시작하기 전에 어떤 방향으로 진행할지(바꿀 오브젝트·파일, 방법, 기존 것을 지우는지/유지하는지, 영향 범위)를 먼저 제시하고, 사용자가 승인하면 그때 시작한다. 2026-11-18 사용자 지시: "지금부터 내 의도를 제대로 네가 파악했는지 확인하기 위해서 작업을 진행하기 전에 어떤 방향으로 진행할지 제시를 하고 내가 승인하면 시작해."

**Why:** 로딩창 "병합" 요청을 내가 새 로딩창(TransitionCanvas/LoadingPanel)에 기존 배경을 옮기는 쪽으로 해석해 스크립트까지 만들었는데, 사용자 의도는 기존 로딩창 Canvas 안에 새 내용을 구현하는 것이었음. 해석이 엇갈린 채 작업이 진행됨.
**How to apply:** 요청의 해석이 둘 이상 가능하거나 기존 오브젝트를 바꾸는 작업이면 반드시 계획(번호 목록)을 먼저 보여 주고 멈춤. "병합/적용/변경" 같은 말은 어느 쪽이 남고 어느 쪽에 넣는지 명시. 관련: [[colossame-ui-rollout-workflow]]
