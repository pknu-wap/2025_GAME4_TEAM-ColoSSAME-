답변은 사용자가 꼭 보고 판단해야 하는 핵심 내용만 담는다. 긴 표·근거·자체 검증 과정·변경 이력 나열은 빼고, 결정이 필요한 것과 결과만 짧게. (2026-11-26, 소식통 시안 작업 중 "대답이 너무 길어 일일이 읽기에 시간이 오래 걸린다"고 지적)

**Why:** 사용자가 답변을 다 읽는 데 시간이 너무 오래 걸림. 불필요한 정보 교환을 줄이길 원함.

**How to apply:** 결과는 2~4줄, 결정할 것은 질문 1~2개로. 세부(좌표·에셋·검증 내역)는 시안 파일 표나 PR 본문에 두고 답변에는 넣지 않는다. 자체 검증은 하되 "무엇을 고쳤는지" 목록은 생략, 남은 문제만 한 줄.
