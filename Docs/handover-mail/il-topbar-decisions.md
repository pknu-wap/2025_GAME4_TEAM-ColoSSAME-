# 상단 바 결정 사항 (다음 작업용, 2026-11-25)

- Book 씬 모든 책갈피 페이지에 고정 표시.
- 왼쪽: 가문 문양만(깃발 그림 대신) + 가문 이름 + Lv. 문양 단독 그림은 프로젝트에 없음 → team_N 깃발에서 잘라 쓰거나 새로 준비(다음 작업에서 결정).
- 가운데: 리그 등급 이름(league.settings.tierName, 예 "입문 리그").
- 오른쪽: 보유 골드(item_money 아이콘) + 설정 톱니(btn_icon + ui_settings). 둘 사이 간격 충분히(오클릭 방지).
- 설정 톱니 옵션 안에 "메인 메뉴로" 배치.
- 남은 경기 수는 넣지 않음(책 "최근 경기" 오른쪽 "n / 27경기" 진행도와 겹침).
- 배경 깃발(화면 왼쪽, HouseBanner 흔들림)도 다음 작업.
- 빨간 알림 점: 진행 안 함.
