## 3. 승인된 소식통 설계 (요약)
- **왼쪽 = 경기 카드 묶음**: 이번 라운드 4경기(우리 경기 제외)를 카드로. 앞 카드 = 고른 경기, 뒤 3장은 머리(대진 + 상태)만 보임. 머리를 누르면 카드가 앞으로 나옴(책 넘김 아님).
  - 앞 카드 3구역(구분선, **결과를 정하는 값은 숨김** — 예상 확률·전력 없음, 용병 정보는 대회 페이지): ① 가문 vs 가문 + 순위 ② 최근 5경기 칩 ③ 최근 맞대결 3칸 일정 칩.
  - **투기장 소식(라운드 공통, 기존 `ArenaNewsUI` 그대로)**: "대회에서 자세히 보기" 버튼 바로 위에 리그 소식·경기장 소문·우리 팀 여론 각 1줄(기존 3줄 그대로). 경기를 바꿔도 그대로(팀원 의견 "소식 삭제 시 몰입도 하락" 반영).
  - **전력 계산 변경(엄지원 님 코드, PR 리뷰 요청)**: `EnemyTeamService.GetTeamPower` = 용병마다 레벨×4 + 등급×6 + 장착 스킬 수×3 의 합. 전력은 라운드 후 적 가문 성장으로 자동 갱신되므로 별도 저장 불필요.
  - 결과 계산에 안 쓰이는 정보(최근 5경기·맞대결·순위·새 스킬)는 넣지 않음.
  - 아래: "대회에서 자세히 보기" 버튼 → BookPageId.League.
- **오른쪽 = 클립으로 꽂은 베팅 전표**(높이 축소): 결과 3칸(배당 "×1.65"), 누르면 그 칸이 어둡게(진갈색 바탕 + 밝은 글자) / 금액은 **더하기 버튼 +10·+50·+100·최대 / 초기화** 5개(공통 UI 평평한 버튼 `btn_secondary_*`, 전표 안쪽 폭에 균등 배치, 누를 수 없으면 숨기지 않고 비활성 표시. 초기화 글자는 빨강) / "적중 시 n G".
  - **라운드 베팅 한도 500 G**(보유 골드와 한도 중 작은 값까지). 한도는 이후 **시설 업그레이드 페이지에서 증액** 예정 → PR에 명시.
  - 왼쪽 카드 머리 상태: "베팅 전" / 베팅 금액만 "n G"(라운드마다 초기화되므로 '마감'·'봉인' 표시 없음). 우리 경기 베팅은 하지 않음(이기면 이미 보상). 결과+금액을 고르면 자동으로 **담음**(왼쪽 카드 머리 "담음 100 G", 경기별 저장).
  - 페이지 아래: "총 베팅 금액", "모두 적중 시" 두 줄 → 그 위 문구 "n건 베팅 확정 · 총 n G" → 버튼 **"베팅 확정"**(담은 전표 전체를 한 번에 확정, 골드 차감). 봉인 그림은 쓰지 않음.
  - **한 번 확정하면 그 라운드는 마감**(추가·취소 없음). 담은 총액 > 보유 골드면 버튼 비활성 + "골드 부족 · n G 더 필요".
  - 순이익 표시·무승부 안내·지난 결과/시즌 성적은 간소화를 위해 삭제.
- **정산 알림**: 경기 후 소식통을 처음 열 때 지난 전표에 적중/빗나감 도장 + 합계.
- **확률·배당**(지금 경기 계산과 같게): 무승부 d = 15%→3%(전력 차이), A 승 = (1−d)×전력비, B 승 = (1−d)×(1−전력비). 배당 = 0.9 ÷ 확률, 상한 승 5배·무승부 10배.
- 같은 페이지 안 내용 교체는 **책 넘김 없이 책 위 물건(카드·전표)이 움직이는 것**으로 표현(사용자 결정).

## 4. Unity 적용 계획 (아직 미승인 — 시작 전에 사용자 확인)
1. 에셋: 카드·클립·잉크 동그라미·밀랍 봉인·도장·접힌 귀퉁이를 공통 UI 색/규칙으로 생성(공통 UI 원본 `ColoSSAME_UI_Claude/tools/final9.py`, Notion "공통 UI" 페이지 첨부 zip), 임시 아이콘(stat_agility·fac_mail, 아이콘은 **보류 중**).
2. 베팅 기능(엄지원 님 코드 → PR에 리뷰 요청 명시): `Prediction`에 `stake`·무승부 선택 추가(예전 저장 = 0 → 기존 10G×배당), `PredictionManager` 4경기 생성(예전 저장은 채워 넣기)·`SpendGold` 차감·적중 시 판돈×배당·무승부 판정·취소(환불).
3. 새 표시 스크립트(내 범위): 카드 묶음·전표·정산 알림, 계산은 `Common/LeagueQuery`에 추가. 전력은 `EnemyTeamService.GetTeamPower`(용병 레벨 합 × 4) 읽기만.
4. Mail 프리팹: BookPage `content` 안에 새 배치. **Home 때처럼 크기 0 오브젝트로 좌표가 밀리는지 먼저 확인**, 적용 후 화면 좌표로 시안 비교.
5. Localization 키, Canvas 붙인 상태 글자 칸 확인, 가짜 데이터로 4경기·판돈·적중·무승부·예전 저장 검증.
6. 커밋 → `git push` → 초안 PR(본문 형식은 #171·#175 참고), 병합은 사용자 지시 때만.

### PR에 보류 사항으로 적을 것
- 리그 소식·경기장 소문을 **선택한 경기의 두 가문 기준**으로 보여 주기: 지금 `ArenaNewsGenerator`는 라운드마다 리그 소식 1개(전체 경기 중 최고 사건), 소문 1개(다음 상대 가산점)만 만들어 가문별로 바뀌지 않음. 가문별 조회 기능 추가 필요(엄지원 님 코드) → 보류.

### 아직 답이 필요한 것
